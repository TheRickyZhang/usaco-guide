<Spoiler title="Hint 1">

For a segment of size $2$, let's break it down into two segments of size $1$.
Notice that if both segments share the same value, then the minimum number of paintings to paint this size $2$ segment is the sum of the two size $1$ segments minus $1$.
Otherwise, it's just the sum of those two segments.

</Spoiler>

<Spoiler title="Hint 2">

Can you generalize this property to any segment that starts from $a$ to $b$?

</Spoiler>

<Spoiler title="Solution">

## Explanation

Define $\texttt{dp}[i][j]$ as the minimum number of paintings to paint the range
$[i, j]$. Then, one of two things can happen when combining ranges
$[i, j], [j + 1, k]$:

1. $A[i] == A[k]$. This means that the range $[i, k]$ has a common color for each
   endpoint. Therefore, we can "save" a color when merging the two ranges.
   $$
   \texttt{dp}[i][k] = \min(\texttt{dp}[i][k], \texttt{dp}[i][j] + \texttt{dp}[j + 1][k] - 1)
   $$
2. $A[i] \neq A[k]$. This means that there is no common color for the endpoint.
   Since we cannot "save" a color when merging the two intervals, simply add
   them together.

$$
\texttt{dp}[i][k] = \min(\texttt{dp}[i][k], \texttt{dp}[i][j] + \texttt{dp}[j+1][k])
$$

## Implementation

**Time Complexity:** $\mathcal{O}(N^3)$

```cpp
// CodeSnip{CPP Short Template}

const int MAX_N = 300;

int A[MAX_N], dp[MAX_N][MAX_N];

int main() {
	setIO();

	int n;
	cin >> n;

	for (int i = 0; i < n; i++) cin >> A[i];

	for (int i = 0; i < n; i++) {
		for (int j = 0; j < n; j++) { dp[i][j] = MAX_N + 1; }
	}

	for (int i = 0; i < MAX_N; i++) dp[i][i] = 1;

	for (int s = 0; s < n; s++) {
		for (int i = 0; i < n - s; i++) {
			for (int j = i; j < i + s; j++) {
				int k = i + s;
				if (A[i] == A[k]) dp[i][k] = min(dp[i][k], dp[i][j] + dp[j + 1][k] - 1);
				dp[i][k] = min(dp[i][k], dp[i][j] + dp[j + 1][k]);
			}
		}
	}

	cout << dp[0][n - 1] << endl;
}
```

```java
import java.io.*;
import java.util.*;

public class ModernArt3 {
	public static final int MAXN = 300;
	public static int[] painting = new int[MAXN];
	// dp[i][j] is the number of moves to paint from i to j.
	public static int[][] dp = new int[MAXN][MAXN];

	public static void main(String[] args) throws IOException {
		BufferedReader in = new BufferedReader(new InputStreamReader(System.in));
		int N = Integer.parseInt(in.readLine());
		StringTokenizer st = new StringTokenizer(in.readLine());
		for (int i = 0; i < N; i++) { painting[i] = Integer.parseInt(st.nextToken()); }

		for (int i = 0; i < N; i++) {
			for (int j = 0; j < N; j++) { dp[i][j] = MAXN + 1; }
		}
		for (int i = 0; i < N; i++) { dp[i][i] = 1; }
		for (int s = 0; s < N; s++) {
			for (int i = 0; i < N - s; i++) {
				for (int j = i; j < i + s; j++) {
					int k = i + s;
					// Merge the 2 ranges
					if (painting[i] == painting[k]) {
						dp[i][k] = Math.min(dp[i][k], dp[i][j] + dp[j + 1][k] - 1);
					}
					// Sum of the both parts
					dp[i][k] = Math.min(dp[i][k], dp[i][j] + dp[j + 1][k]);
				}
			}
		}
		System.out.println(dp[0][N - 1]);
	}
}
```

<Spoiler title="Optimization">

Generally, the structure of range DP yields an $O(n^3)$ solution, but the collapsible structure of this painting lets you skip most splits.

**Key idea.** Let $a$ be the array after **run-length compression** (merge consecutive equal colors). Define
$$
dp[i][j]
=\min\Big(
  dp[i][j-1]+1,\;
  \min_{\substack{i\le k<j\\ a[k]=a[j]}}
    \big(dp[i][k-1]+dp[k][j-1]\big)
\Big),
$$
with the convention $dp[i][i-1]=0$.

This is correct by the **last stroke** argument: the final stroke must paint $j$ with color $a[j]$. Either it paints only $j$ (first term) or it also covers some earlier $k$ with the same color (second term). Splits with $a[k]\ne a[j]$ cannot share the last stroke and are never better than painting $j$ alone.

This optimization keeps the same worst-case bound but is much faster in practice, often close to $O(n^2)$ after compression.

```cpp
// CodeSnip{CPP Short Template}
// Modern Art 3 — optimized "same-color end" DP with run-length compression.

int main(){
  setIO();

  int n; cin>>n;
  vi a(n);
  for(int i = 0; i < n; i++) cin>>a[i];

  // Run-length compress consecutive equal colors.
  vi b; b.reserve(n);
  for(int i = 0; i < n; i++) {
    if(b.empty() || b.back() != a[i]) {
      b.pb(a[i]);
    }
  }
  n = b.size();
  if(n == 0){
    cout<<0<<endl;
    return 0;
  }

  // prev[j] = previous index < j with same color as b[j], or -1.
  int mx = 0;
  f(i,n) mx = max(mx, b[i]);
  vi last(mx+1, -1), prev(n, -1);
  f(j,n){
    prev[j] = last[b[j]];
    last[b[j]] = j;
  }

  vector<vi> dp(n, vi(n, 0));
  for(int i=n-1; i>=0; --i){
    dp[i][i] = 1;
    for(int j = i+1; j<n; ++j){
      // paint j alone;
      int best = dp[i][j-1] + 1;
      for(int k = prev[j]; k >= i; k = prev[k]) {
        // only same-color splits
        best = min(best, (k==i ? 0 : dp[i][k-1]) + dp[k][j-1]);
      }
      dp[i][j]=best;
    }
  }
  cout << dp[0][n-1] << endl;
  return 0;
}
```
